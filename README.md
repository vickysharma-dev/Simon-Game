# 🎮 Simon Game

A fun and interactive memory game built using HTML, CSS, and JavaScript. Test your memory by repeating the color sequence and try to achieve the highest score!

## 🚀 Live Demo

**[Play Simon Game](https://vickysharma-dev.github.io/Simon-Game/)**

## ✨ Features

- Interactive and colorful game interface
- Memory-based color sequence challenge
- Increasing difficulty as the game progresses
- Score tracking to test your memory
- Simple and user-friendly design

## 🛠️ Technologies Used

- HTML5 — Structure of the game
- CSS3 — Styling and layout
- JavaScript — Game logic and interactivity

## 🎯 How to Play

1. Start the game.
2. Watch the color sequence carefully.
3. Repeat the sequence by clicking the colored buttons in the correct order.
4. Each round adds a new step to the sequence.
5. Continue as long as you remember the correct sequence!

## 💻 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/vickysharma-dev/Simon-Game.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.
